Generated by `ml/evaluate.py` from the shipped model (`studyroute-nlu-v1`, 33.8 MB, int8 dynamic (weights)); do not edit by hand. Every number below is measured on data the model never trained on and no threshold was tuned on. See [AI_AGENT.md](AI_AGENT.md) for the design, the dataset card and the limits.

Systems: **rules** is the assistant's original regex reader plus its policy filter. **reader** is the trained model alone. **agent** is what the product runs: the reader, the deterministic checks, the confidence thresholds and the policy filter together.

Routing accuracy treats HELP and OUT_OF_SCOPE as one class, because both answer with the help text; this is the kindest reading for the baseline.

## Cost

The model runs on CPU with ONNX Runtime: median 6.55 ms and 95th percentile 10.72 ms per message (n = 436, 2 threads). The file is 33.8 MB.

## How to read this honestly

* The training and test messages are mostly **synthetic**. The model learns the patterns of the generator, so the first table is a sanity check and the held-out and hard tables carry the weight. No real parent's messages were used.
* The hard set is small (136), so differences of a few points are within noise; the confidence intervals show it.
* A fixed phrase list is hard to beat on messages it was written for. The reader's advantage is on wording the rules do not contain; the agent column shows what is kept once the deterministic checks and thresholds are applied.
* "Wrongly starts an action" counts messages that are not requests for a quote, draft or approval request but were routed to one. Even then the assistant only proposes: it cannot approve, and a person still clicks.
