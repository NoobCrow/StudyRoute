# Third-party components and licences

Generated by `python scripts/gen_third_party.py`. Do not edit by hand.

StudyRoute's own code is original work by the team. It uses the open-source components
below, each under its own licence, one public data set (Banking77, credited below) and one
pretrained model that the team fine-tuned. The exchange rates, providers, fees, people and
accounts in the sandbox are invented by the team. The competition rules require
third-party components to be properly licensed; this is the inventory. Only direct
dependencies are listed; the exact versions of everything installed are pinned in
`backend/requirements.txt`, `frontend/package-lock.json` and `contracts/package-lock.json`.
